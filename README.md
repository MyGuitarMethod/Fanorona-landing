# Fanorona — public landing page

The standalone product website for **Fanorona by MinnyMedia**.

Published with GitHub Pages from the root of `main`:
https://myguitarmethod.github.io/Fanorona-landing/

This repository contains website HTML, CSS, browser interactions, selected optimized promotional artwork, and genuine game screenshots. It does not contain the Godot game source, builds, player saves, signing material, or credentials.

Open `index.html` through any local static web server to preview. No package installation, build step, backend, analytics, accounts, or form submission is required.

## Content

- `index.html`: product copy and accessible page structure.
- `styles.css`: responsive emerald/white styling, with reduced-motion support.
- `script.js`: mobile navigation, character previews, collection tabs and keyboard-accessible image previews.
- `assets/`: selected web-sized artwork and screenshots from the development build. Screenshot views may show progressed/unlocked content.

The game is in development for Android. The page intentionally makes no store availability, release date, purchase, multiplayer, or achievements promises. Add a store link only after its public listing is verified.
